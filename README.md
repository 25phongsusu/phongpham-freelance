# Landing page dịch vụ quảng cáo Facebook

Website tĩnh, không cần cài đặt thư viện hoặc chạy bước build.

Website đang hoạt động tại: <https://25phongsusu.github.io/phongpham-freelance/>

## Xem trên máy

Mở `index.html` trực tiếp, hoặc chạy một web server tĩnh trong thư mục dự án.

## Thông tin dễ chỉnh sửa

- Nội dung trang: `index.html`
- Màu sắc và bố cục: `styles.css`
- Biểu mẫu và xem ảnh lớn: `script.js`
- Ảnh và báo cáo: thư mục `assets/`

Biểu mẫu liên hệ dùng `mailto:` và sẽ mở ứng dụng email của người xem. Zalo và số điện thoại là liên kết trực tiếp.
